# Strong PPL — Native Android project

A native, offline-first Android workout tracker for the fixed 12-week PPL programme.

## Current implementation
- Kotlin + Jetpack Compose UI
- Room database for set logs and workout sessions
- DataStore stores the programme's Monday anchor
- Fixed weekday schedule: Mon Push A, Tue Pull A, Wed Legs A, Thu Push B, Fri Pull B, Sat Legs B, Sun Rest
- Missed sessions do not shift later workouts
- Per-set reps, kg, RIR and band/setup notes
- Previous-set comparison
- Automatic local saving
- History, basic analytics, JSON backup and restore
- GitHub Actions workflow to build a debug APK

## Build an APK using GitHub Actions
1. Create a **new** GitHub repository, e.g. `strong-ppl-android` (keep the old PWA repository separate).
2. Upload the contents of this project folder to the repository root, including `.github/workflows/android-apk.yml`.
3. Open the repository's **Actions** tab and run **Build Android APK** (or push a change to `main`).
4. Open the successful workflow run. Under **Artifacts**, download `strong-ppl-debug-apk`.
5. Extract the ZIP to obtain `app-debug.apk` and install it on the Android phone. Android may ask permission to install apps from that source.

The APK generated by this workflow is a debug build for personal testing, not a Play Store release. A signed release build should be configured separately before public distribution.

## Important calendar rule
The programme anchor is the Monday of the calendar week on first launch. Weekday assignment is always based on the actual weekday, never the installation day or workout completion. Sunday is always rest. Missing a workout does not move the next day's workout.

## Data safety
Workout records are stored locally in the app's Room database. Export a JSON backup regularly. Restoring a backup replaces local workout history. The backup contains a schema version and is validated before the database replacement transaction.

## Current limitations / next validation
- This environment does not include Android SDK/Gradle, so the APK cannot be compiled or device-tested here. GitHub Actions is configured to perform the actual Android build.
- Test the debug APK on the target Samsung phone before relying on it for long-term workout records.
- Analytics are currently foundational summaries; richer charts and exercise PR trends are planned for a subsequent iteration.
- No exercise media is bundled yet; the programme includes text and safety notes.
